This repository holds code to perform an analysis that identifies potential spruce swamp restoration areas in both current estuaries and under various sea level rise scenarios of the users choosing. Data for estuary extents
and Landward Migration Zones (LMZs) are provided in the 'data' folder. Input data folder can be found in the 'Releases' section of this repository.

Note: Users must first download bare-earth DEMs TIFF files (.tif) covering their area of interest and put them in the 'dems' folder before running analysis. 
Code is provided to mosaic multiple DEMs as needed.
